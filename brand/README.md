# Ember brand images

All of these are drawn by `web/build/make-brand.mjs` from one flame mark, the app's colours and its display typeface (Bricolage Grotesque). Change the script and run it again rather than editing the images by hand.

| File | Use |
|---|---|
| `mark.svg` | the flame alone |
| `app-icon.svg` | the app icon, rounded |
| `app-icon-1024.png` | the icon the App Store and Play Store ask for: square, no transparency |
| `logo-on-light.png`, `logo-on-green.png` | flame and name on the app's two grounds |
| `logo-transparent-dark-text.png`, `logo-transparent-light-text.png` | the same with no ground, for light and dark surfaces |

The site's own icons, iPhone start-up screens and link-preview image are in `web/public/`.

Colours: green `#0f3d2e`, ember `#e4511b` (on light) and `#ff6b36` (on green), paper `#ecefea`, ink `#12211b`.
